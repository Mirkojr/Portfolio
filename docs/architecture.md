# Arquitetura

## Visão Geral

A arquitetura desse projeto portfolio é simples, foi feito em Html, CSS e JavaScript, dado o objetivo de hospedá-lo em uma plataforma gratuita, como o GitHub Pages. 

Para auxiliar na estilização, foi utilizado o framework Bootstrap, e para os ícones, foi utilizado o Font Awesome. Além disso, foram utilizadas fontes do Google Fonts para melhorar a tipografia do projeto.

A estrutura do projeto é modular, com cada seção do portfolio sendo representada por um arquivo HTML separado. Para facilitar a manutenção e adição de novas seções posteriormente.

# Ferramentas utilizadas

- Scalidraw
Utilizado para a concepção da estrutura do site, uma ferramenta de desenho colaborativa que permite criar diagramas e fluxogramas de forma rápida e intuitiva.

- Visual Studio Code
Utilizado como editor de código, devido à sua interface amigável e recursos avançados, como depuração, controle de versão e extensões que facilitam o desenvolvimento web.

- GitHub
Utilizado para hospedar o projeto e gerenciar o controle de versão.
